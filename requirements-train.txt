#   pip install -U pip

# IMPORTANT — torch and your CUDA driver
# --------------------------------------
# The PyPI torch wheel now bundles CUDA 13 runtime libs. If your driver is older
# (CUDA 12.x), install torch FIRST from the matching PyTorch index, THEN this file:
#
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
#   pip install -r requirements-train.txt
#
# Check with `nvidia-smi` (top-right shows max supported CUDA) before you start.
# Getting a CPU-only torch by accident is the single most common way to "discover"
# that YOLO11x trains slowly.
